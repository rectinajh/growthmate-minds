# 声线（TTS）决策

## 结论（已确认，2026-08-25）

**演示采用「仅文字草稿」方案**（用户在 issue 提问卡中确认）；预录声线 / 第三方 TTS 留作赛后产品化增强，不在本次黑客松演示中实现。

## 依据

1. Minds 当前无内置语音合成能力；官方 FAQ 未列 TTS，需要通过 `HTTP_Execute` 调用外部 REST 端点。
2. 接第三方 TTS 需创作者授权录音样本、处理时延/成本/版权，属于黑客松时间窗内的高风险项。
3. 评审重点在「记忆 / 连续性 / 自主跟进」的 Minds 集成深度，声线是可感知的加分项而非必要条件。

## 两级方案

| 级别 | 内容 | 成本 / 风险 | 适用 |
|---|---|---|---|
| 已确认（MVP） | 文字草稿（用创作者语气），不展示语音 | 低 | 现场演示、提交通用 |
| 增强（赛后） | 预录声线片段 或 `HTTP_Execute` 调 ElevenLabs 等 voice-clone 服务 | 需授权样本、成本、时延 | 赛后产品化 |

## 若走完整版

1. 创作者提供并授权录音样本。
2. 在 Minds 的 My Connections 配置对应服务的 API key（平台保存 key，Mind 不直接持有）。
3. 用 `HTTP_Execute` 定义 Tool Schema：输入文本、声线 ID，返回音频 URL。
4. 在「关系连续性」Skill 的回复草稿中附加该音频，仍保持「待确认」。

## Bazaar 参考

公开 Bazaar 中已存在 Telegram Voice 类技能（Whisper STT + ElevenLabs TTS），可作为声线功能的技术参照；GrowthMate 的差异在「先用长期记忆生成个性化文本，再合成声线」，而非纯语音管道。
