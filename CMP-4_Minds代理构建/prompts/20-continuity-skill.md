# 构建技能：关系连续性（连续）

请为我构建一个 Skill，名字叫「关系连续性（Continuity）」。它保证创作者回复粉丝时「记得昨天、不把老粉当新粉」。

要求：
1. 在任何回复动作前，必须先调取该粉丝的 Episode / Tenet 画像，并在草稿中引用历史上下文（例如「看到你上次问的汤底配方…」），禁止泛泛地说「新朋友你好」。
2. 为每条粉丝关系打一个「连续状态」：
   - 新粉：首次互动，建立画像并欢迎。
   - 熟粉：多次互动，引用共同记忆。
   - 待转化：连续 3 次以上互动但仍未关注，给出轻量、自然的关注引导。
3. 输出「关系连续性评分」（0–100）与一句话理由：粉丝被记住的比例越高、回访越连贯，分数越高。
4. 对高价值评论（提问、催更、晒单、纠错、深度共鸣）优先产出草稿；对灌水评论只记录不打扰。
5. 仍然遵守默认「待确认草稿」边界，不自动对外发布。

请先向我读回你会如何判断「新粉 / 熟粉 / 待转化」，以及草稿如何引用昨天或上周的记忆。
