# 构建技能：粉丝记忆（记忆）

请为我构建一个 Skill，名字叫「粉丝记忆（Fan Memory）」。它负责把创作者与粉丝之间的互动变成可检索的长期记忆。

要求：
1. 数据落库用你原生的分层记忆：
   - 每条互动写入 Episode：粉丝昵称、平台、时间、互动内容、粉丝意图、我的回复状态、待跟进事项。
   - 把可复用的长期事实提炼为 Tenet，例如「@kiki 是健身粉，上次问增肌餐」「发新视频后 24 小时内回复效果最好」「创作者口头禅：别急～」。
2. 支持三类查询，用中文自然语言回答：
   - 「昨天谁最活跃？」→ 按互动密度列出粉丝并说明为什么。
   - 「我答应过谁什么？」→ 列出所有未完成的承诺和跟进日期。
   - 「说说 @某人 的画像」→ 汇总该粉丝的历史互动、偏好和关系阶段（新粉/熟粉/待转化）。
3. 每次记录新互动时，先检索是否已有该粉丝的 Episode；有则追加关联，没有则新建，不要重复建同一粉丝的多份画像。
4. 不做任何对外发布动作；本技能只读写记忆，所有输出都是给创作者看的中文摘要。

请先向我读回你理解的工作方式，并说明你会用哪些记忆层（Episodes / Tenets）分别存什么。
