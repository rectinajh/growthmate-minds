# 涨粉参谋（GrowthMate）— 演示视频分镜与视觉系统

- 版本：v1（设计师定稿，待与产品研究员 CMP-3 脚本对齐微调对白）
- 时长目标：105 秒（成片可用 1:40–2:00 区间）
- 规格：1920×1080 · 30fps · H.264 MP4
- 语种：中文旁白（Tingting）＋中英文字幕/关键标签

## 1. 设计目标

让评审在 2 分钟内看懂 GrowthMate 的三大核心行为，并相信它能「替代创作者每天的低效重复劳动」：

- 记忆（Memory）：记住粉丝身份、历史互动与创作者个人声线。
- 连续（Continuity）：跨天接续昨日互动，不漏掉任何一次高价值回复。
- 自主（Autonomy）：无需提示，自动生成每日增长简报与行动建议。

视觉上以「夜间工作室 + 数据仪表盘」为核心隐喻：暗色深蓝底、霓虹紫/青双主色，专业、克制、有科技感。

## 3. 三行为视觉锚点

- 记忆 = 「紫色记忆节点/时间线」+ 语音波形。
- 连续 = 「昨天→今天」的时间线接力动画。
- 自主 = 「晨间自动推送」卡片 + 日程/行动清单。

## 5. 关键对白（旁白全文）

1. 创作者每天都要面对同一个问题：怎么涨粉，怎么留住每一次互动？
2. 现在，把这件事交给 GrowthMate——一个常驻 Minds 的涨粉参谋。它不只会聊天，它记得、会连续跟进、还会主动替你行动。
3. 我们来看现场演示。创作者一键连接 Minds 账号，GrowthMate 就开始观察内容和粉丝，建立你的长期记忆。
4. 第二天早上，它记得昨天表现最好的视频，还提醒你：这条高价值评论，值得马上回复。
5. 无需任何提示，它会自动生成增长简报：粉丝趋势、视频表现，还有今天最该做的那一件事。
6. 它用你说话的方式帮你草拟回复——语气、习惯、甚至口吻都像你本人。你只要点一下确认，互动就完成。
7. 记住每一位粉丝，持续跟进每一次互动，自主处理每天的琐事。成长，不再只靠运气。
8. GrowthMate：你的常驻涨粉参谋。让每一次互动，都变成增长。
